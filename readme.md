Bubble Sort
---
Algoritmo simples de ordenação no qual pega o menor, valor e joga pra direita por isso o nome Bubble de bolha


A sua implementação é simples utilizando Array, ponteirs, e algumas validações para garantir, performance

No entanto é recomendavel utilizar, em lista consideravelmente pequenas pelo fato de sua notação Big O(n^2) não ser das melhores....
